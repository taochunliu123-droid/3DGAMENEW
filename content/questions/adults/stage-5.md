# 照範例寫 | Follow the Sample
答案：B

## 情境
你有一篇很喜歡的舊產品介紹。
## Scenario
You have an old product description you love.

## 問題
哪一句最好？
## Question
Which one is best?

## A
請寫新產品介紹。
## A (EN)
Write a new product description.

## B
請照這篇範例的長度和語氣，寫新產品的介紹。
## B (EN)
Match this sample's length and tone to write the new product description.

## C
請寫一篇比範例更長的。
## C (EN)
Write one longer than the sample.

## D
範例寫得好嗎？
## D (EN)
Is the sample good?

## 解析
給範例，AI 就能對齊你要的風格。
## Why
A sample helps AI match the style you want.

## 提示
有沒有現成的好例子可以給 AI？
## Hint
Is there a good example to give AI?

# 只看合約 | Contract Only
答案：A

## 情境
你想問合約裡的付款條件。
## Scenario
You want to ask about payment terms in a contract.

## 問題
哪一句最好？
## Question
Which one is best?

## A
請只根據附件合約回答；合約沒寫的，就說「未提及」。
## A (EN)
Answer only from the attached contract; if it's not there, say 'Not mentioned.'

## B
請根據一般做法回答。
## B (EN)
Answer based on common practice.

## C
請上網查一般合約怎麼寫。
## C (EN)
Look up how contracts are usually written.

## D
不確定的就推測。
## D (EN)
Guess if unsure.

## 解析
限定資料來源，可以避免 AI 編出合約沒有的條款。
## Why
Limiting the source stops AI from inventing clauses.

## 提示
答案只能從哪裡來？
## Hint
Where must the answer come from?

# 活動簡介 | Event Blurb
答案：D

## 情境
簡介要放在海報上，不想要誇張用詞。
## Scenario
The blurb goes on a poster; you don't want hype words.

## 問題
哪一句最好？
## Question
Which one is best?

## A
請寫活動簡介。
## A (EN)
Write an event blurb.

## B
請寫得越吸引人越好。
## B (EN)
Make it as catchy as possible.

## C
請寫一篇完整的活動介紹。
## C (EN)
Write a full event description.

## D
請寫 50 字以內的活動簡介，不要用「革命性」這類誇張詞。
## D (EN)
Write an event blurb under 50 words, without hype words like 'revolutionary'.

## 解析
字數限制加上「不要什麼」，結果就接近你要的樣子。
## Why
A word limit plus 'don't' gets close to what you want.

## 提示
有哪些限制要先講？
## Hint
Which limits should you state first?

# 保留數字 | Keep the Numbers
答案：A

## 情境
你想潤飾一段文字，裡面有日期和金額。
## Scenario
You want to polish text that contains dates and amounts.

## 問題
哪一句最好？
## Question
Which one is best?

## A
請潤飾這段文字，但不要改動任何數字和日期。
## A (EN)
Polish this text, but don't change any numbers or dates.

## B
請潤飾這段文字。
## B (EN)
Polish this text.

## C
請重寫這段文字。
## C (EN)
Rewrite this text.

## D
請把這段寫得更長。
## D (EN)
Make this longer.

## 解析
說出「不要改什麼」，重要資訊就不會被改掉。
## Why
Saying what not to change protects key information.

## 提示
哪些東西一定不能動？
## Hint
What must stay untouched?
